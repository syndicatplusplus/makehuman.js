1. Build the updated app
In Git Bash:

cd /z/github/makehuman.js
npm run build

Let that finish completely. The important ending should look roughly like:
created dist/makehuman.js ...

followed by the build:chai step and then your normal $ prompt returning.

2. Recreate the production folder
Once the build succeeds, run:

rm -rf /z/github/makehuman-deploy
mkdir -p /z/github/makehuman-deploy
cp -a index.html favicon.ico style static data dist /z/github/makehuman-deploy/

Then verify it:

du -sh /z/github/makehuman-deploy
ls /z/github/makehuman-deploy

You should see:
data
dist
favicon.ico
index.html
static
style

And because we're copying the whole static directory, your X Bot JSON comes along automatically too.
3. Copy that folder to NYANPOSER-WEB
Then replace the contents of the NAS share with the contents of:
Z:\github\makehuman-deploy

So the root of NYANPOSER-WEB should once again directly contain:
data/
dist/
static/
style/
favicon.ico
index.html

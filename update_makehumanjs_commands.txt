1. Build the updated app
In Git Bash:

cd /z/github/makehuman.js
npm run build

Let that finish completely. The important ending should look roughly like:
created dist/makehuman.js ...

followed by the build:chai step and then your normal $ prompt returning.

2. Recreate the production folder. Once the build succeeds, run:

rm -rf /z/github/makehuman-deploy
mkdir -p /z/github/makehuman-deploy
cp -a index.html favicon.ico style static data dist /z/github/makehuman-deploy/

Then verify it:

du -sh /z/github/makehuman-deploy
ls /z/github/makehuman-deploy
